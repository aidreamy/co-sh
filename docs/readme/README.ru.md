# co-sh

Cosh — универсальный coding agent для терминала с инструментами разработки ПО и *computer tools*, позволяющими взаимодействовать с графическими приложениями.

## Почему co-sh?

co-sh не призван заменить устоявшиеся coding agents — он создан, чтобы работать рядом с ними как слой оркестрации. Вот почему он может вам пригодиться:

- **Мультиагентная работа** — Запускайте разные передовые агенты (Claude, Gemini, Codex, Cline и др.) прямо в одном TUI, создавая общее рабочее пространство, где они могут общаться и сотрудничать через единый интерфейс.
- **Удобно для экспериментов** — Идеально для разработчиков, которые любят пробовать разных агентов и объединять их сильные стороны, а не привязываться к одной экосистеме.
- **Режим менеджера** — Продолжайте использовать свои существующие harness'ы агентов, добавляя поверх оркестрацию; особенно удобно при работе над несколькими небольшими задачами одновременно.
- **Нативный TUI-опыт** — Провайдеры, модели и режимы работы настраиваются прямо в интерфейсе при минимальной ручной настройке.
- **Модульная архитектура** — Независимые переиспользуемые крейты для инструментов разработки, компонентов TUI, SDK и recall памяти.

## Чем отличается от других TUI-оркестраторов

co-sh выделяется среди других терминальных оркестраторов агентов несколькими ключевыми особенностями:

| Возможность | co-sh | Другие TUI-оркестраторы |
|-------------|-------|-------------------------|
| **Разделённые панели для нескольких агентов** | Запускайте несколько внешних агентов одновременно в разделённых панелях, у каждого своя сессия, модель и опциональный git worktree | Обычно ориентированы на одного агента или требуют переключения контекста |
| **Computer tools через accessibility tree** | Читает графические интерфейсы и работает с ними через структурированное представление, прибегая к скриншотам только при необходимости | Обычно полагаются на скриншоты или вовсе не умеют работать с GUI |
| **TUI на Rust** | Написана с нуля с использованием Ratatui, вдохновлена UX OpenCode | Часто веб-терминалы или менее оптимизированные интерфейсы |
| **Настройка внутри приложения** | Провайдеры, модели и режимы настраиваются прямо в TUI | Часто требуют внешних файлов конфигурации или флагов CLI |
| **Модульные крейты** | Инструменты разработки, TUI-виджеты, SDK и recall памяти как независимые переиспользуемые библиотеки | Монолитная архитектура с жёстко связанными компонентами |
| **Общее рабочее пространство** | Несколько агентов сотрудничают через единый интерфейс с координированной раздачей задач | Агенты обычно работают изолированно |

Основные возможности:

- **Мультиагентный режим (`/agents`)** — запускайте внешних агентов (Gemini, Claude, Codex, Cline, …) вместе с основным агентом в разделённых панелях, все доступны из одного промпта. У каждого агента своя сессия, модель и опциональный git worktree, а основной агент координирует их — раздаёт задачи и собирает отчёты как одна команда.
- **Computer tools через accessibility tree** — агент читает графические интерфейсы и работает с ними через компактное структурированное представление, а к скриншотам прибегает только как к запасному варианту. Меньше обработанных изображений — меньше расход токенов.
- **TUI, написанная с нуля на Rust** (Ratatui), вдохновлённая UX OpenCode. Настройка провайдеров, моделей и режимов работы выполняется прямо в интерфейсе — почти никакой ручной конфигурации.
- **Независимые крейты** — инструменты разработки вынесены в крейты, не зависящие от приложения, и могут использоваться как библиотеки за пределами Cosh.

## Установка

Протестировано на Linux и Windows. macOS пока не тестировалась — если что-то не сработает, [создайте issue](https://github.com/aidreamy/co-sh/issues) с максимально подробным описанием.

**Linux и macOS** (также работает в Windows через Git Bash / WSL):

```sh
curl -fsSL https://raw.githubusercontent.com/aidreamy/co-sh/main/download.sh | bash
```

**Windows (PowerShell):**

```powershell
irm https://raw.githubusercontent.com/aidreamy/co-sh/main/download.ps1 | iex
```

> Примечание: команда `curl | bash` **не** работает в PowerShell или CMD — в Windows нет нативного `bash`. Используйте скрипт PowerShell выше (Git Bash и WSL тоже подходят).

Необязательные переменные: `COSH_BIN_DIR` (каталог установки), `COSH_VERSION` (конкретная версия) и `COSH_VARIANT` (`slim` — по умолчанию, или `slim-embed` — с локальным RAG через fastembed). В PowerShell задайте их как `$env:COSH_VERSION = "v0.1.0"` перед запуском команды.

После установки запустите `cosh` в терминале. Если каталог установки отсутствует в вашем `PATH`, скрипт сам выведет команду для его добавления. Если возникнут сложности с установкой — создайте issue, буду рад помочь!
